# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Antigravity Claude Bridge, please report it responsibly:

1. **Do not create a public issue** disclosing the vulnerability.
2. Instead, report security bugs via GitHub Security Advisory or email project maintainers.
3. Include details of the vulnerability, affected components, and steps to reproduce.

We take security seriously and will investigate and patch verified vulnerabilities promptly.
