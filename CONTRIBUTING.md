# Contributing to Antigravity Claude Bridge

Thank you for considering contributing to the Antigravity Claude Bridge project!

## How Can I Contribute?

### Reporting Bugs
- Check the issue tracker to see if the bug has already been reported.
- If not, open a new issue using the **Bug Report** template.
- Include clear steps to reproduce, OS version, and relevant terminal logs.

### Suggesting Enhancements
- Open an issue using the **Feature Request** template.
- Explain the motivation and expected behavior of the enhancement.

### Pull Requests
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/my-new-feature`
3. Make your changes and test them thoroughly.
4. Ensure code formatting is clean and scripts execute without syntax errors.
5. Commit your changes: `git commit -m 'feat: add support for new capability'`
6. Push to your branch: `git push origin feature/my-new-feature`
7. Submit a Pull Request.

## Code Style
- Keep shell and batch scripts cross-platform friendly.
- Do not commit any personal tokens, API keys, or machine-specific absolute paths.
- Ensure all automated installers preserve idempotency.
